# 沪港 IPLC 购买：共享、独享与 IX 套餐价格对比，以及下单前必看的限制和流程

上海出发、对端在香港的业务系统，是“沪港 IPLC”这个词背后最典型的需求：ERP 对接、跨境电商的店铺运营、量化交易程序连香港交易所，都吃这条线路的延迟和稳定性。公网绕路、晚高峰丢包、IP 被封端口这类问题，靠换普通 VPS 解决不了，这也是专线产品存在的原因。

## 沪港 IPLC 是什么，21ms 指什么

IPLC 的全称是 International Private Leased Circuit，即国际私有租赁线路。它是一条点对点的私有线路：你从上海入口连进 VPS，程序从香港出口向外访问，跨境段不经过公共互联网。这是它和普通“香港 VPS”最本质的区别——普通 VPS 的流量走公网跨境，质量受国际出口拥堵影响；IPLC 的路径是固定的，不存在“被墙”这个问题。

MKCloud 官方给沪港线路标注的**端内参考延迟是 21ms**。这里有个容易踩的口径问题：21ms 指的是入口到出口的端内延迟，不是你家里电脑到某个香港网站的全部耗时。完整延迟等于“本地到上海入口 + 端内 21ms + 香港出口到目标平台”三段之和。官方知识库也专门提醒过这一点，验收时要分两段分别测，别拿 21ms 当成全链路的承诺。

还有一个架构特点直接影响它能不能用在你的场景里：每台 VPS 分配 1 个独立入口 IP 和 1 个独立出口 IP，**出口只用于向外访问，不支持外部连入**。换句话说，它是给“你的程序主动出去”设计的，不能拿来公开建站、做支付回调或者对外的游戏服务。

## 共享、独享、IX 到底怎么选

官方知识库给过一个选型思路，按用量而不是按“主店小号”来分，这里按同样的逻辑展开：

- **月流量可预估、访问有波峰**：共享款合适。200Mbps 峰值对付白天集中上传、晚间偶发高峰是够的，1TB 档 288 元/月是沪港方向的入门价位。注意峰值不保证持续跑满。
- **需要持续速率或长时间传输**：独享款。5Mbps 看着小，但它是保证带宽，跑一天一夜不会像共享款那样受峰值竞争影响，传输大文件、做持续同步时差别明显。
- **业务已经在阿里云、腾讯云这类平台上**：先看沪港 IX。它从云网络直接接入，省掉一层入口，起步价 158 元/月也是全线最低，[👉 可以先到沪港 IX 套餐页核对支持的云厂范围](https://www.mkcloud.net/aff.php?aff=390&url=https%3A%2F%2Fwww.mkcloud.net%2Findex.php%2Fstore%2Fcloud-sh-hk-sh)。
- **做港股、期货、量化对接港交所**：官方知识库的建议是选沪港 IPLC 独享，物理隔离通道的抖动小，交易场景里延迟抖动比绝对延迟更要命。

一个简单的预算参照：沪港共享入门 288 元/月，独享入门 650 元/月，IX 起步 158 元/月。人不在长三角的话，华南业务选广港 IEPL 更合适（端内 1~2ms，[👉 广港套餐在这里](https://www.mkcloud.net/aff.php?aff=390&url=https%3A%2F%2Fwww.mkcloud.net%2Findex.php%2Fstore%2Fgz-hk-sh)），沪港的价值在于“出发地在华东”。

## 购买流程：从下单到开通要做的事

整个流程在官网上是引导式的，实际步骤如下：

1. 进入商店后先选地区（上海-香港 IPLC 专线），再选网络（上海电信或上海 BGP），然后选类型（流量计费或带宽计费）。
2. 选套餐配置和操作系统。系统镜像覆盖 Ubuntu、Debian、CentOS、AlmaLinux、Rocky、FreeBSD、Alma 等主流发行版，版本从老到新都有。
3. 在附加选项的下拉框里**选择可连入省份**。这是省级白名单机制：开通后只允许该省份的 IP 连入，防止线路被滥用。选错也没关系，后续可以随时修改省份。
4. 勾选服务协议，用支付宝付款。现货套餐通常自动开通，官方资料提到实际时长受支付、库存和系统安装影响。
5. 开通后先做验收：分别测“本地到上海入口”和“VPS 到目标平台”的延迟与速度，把数据截图留好。退款政策只支持质量问题，而且要求提供具体的延迟、速度数据作为证据，这个留证动作不要省。

从选线路到开机，常规套餐本身不需要人工介入，真正花时间的是验收和业务部署这两步。

## 下单前必须知道的几条限制

以下内容都来自官网购买页和知识库的原文，属于“买了之后才知道就晚了”的类型：

- **出口不支持入站**。不能公开建站、不能做支付回调、不能跑对外的游戏服务。它只适合“你的程序从国内主动出去”的模式。
- **需要中国身份信息实名**，仅限个人或企业正规用途，平台通过省级白名单和实名机制排除违规用途。
- **仅质量问题支持退款**，且需在工单里提交具体测试数据由商家审核；服务开通后不支持更换到其他地域的产品，选线路前想清楚。
- **默认无 SLA**。没有可用性赔付承诺，有高可用要求需要先询价定制，别把产品介绍当成服务保障。
- **共享流量双向计费**，超量后暂停，恢复要买流量重置或补差价升级；降级套餐时差价不退。
- **海缆故障可能影响线路**。官方明确说香港出口的多运营商互联不代表跨境段有独立备份，对连续性要求高的业务要先确认保障与恢复约定。

## 几个常见问题

**21ms 是不是我访问香港网站的速度？** 不是。它是入口到出口的端内参考值，全链路要加上本地到入口和出口到目标两段，验收时分开测。

**1TB 流量够用吗？** 按双向合计算。纯办公访问一个月 1TB 大多够，跑持续数据同步的话建议先记录一周实际用量再定档位。

**能不能做网站服务器？** 不能。出口仅出站的架构决定了它和普通香港 VPS 不是一类产品。

**和直接买香港 VPS 比，贵在哪？** 贵在跨境段是私有线路，路径固定、延迟稳定、出口 IP 不受公网跨境波动影响。官方知识库的说法是，比较时要把带宽约定、流量口径、接入条件和服务成本放在一起看，单纯的“倍数论”没有意义。

**人在广东，买沪港还是广港？** 从广东出发，广港 IEPL 端内 1~2ms，延迟不到沪港的一半，没必要舍近求远。沪港适合华东出发或对上海入口有依赖的业务，[👉 各线路套餐可以在商店统一查看](https://bit.ly/MKCLoud)。

沪港这条线在 MKCloud 的产品矩阵里不算最便宜的（IX 更便宜），也不是最快的（广港延迟更低），它的定位很明确：华东出发、对稳定性和合规性有要求、预算从每月几百到几千的业务。共享 1TB 档 288 元/月适合大多数公司做沪港方向办公和电商运营的入门选择；跑持续传输就上独享；已经在云上的先算 IX 这笔账。反过来，如果你要的是能建站的香港服务器，或者想拿来做别的用途，这个产品从架构上就不匹配，买之前把出口仅出站这一条想明白，能省掉后面所有的退款扯皮。
